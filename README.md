# Project Cube 배포

## 처음 한 번

1. [ProjectCubeLauncher.exe 다운로드](https://github.com/rudIsland/Project_Cube-Release/raw/main/ProjectCubeLauncher.exe)
2. 빈 폴더(예: `바탕화면\ProjectCube`)에 넣습니다.
3. Steam → 왼쪽 아래 **게임 추가** → **비 Steam 게임 추가** → **찾아보기**에서 `ProjectCubeLauncher.exe`를 골라 추가합니다.

## 플레이할 때마다

1. **Steam 라이브러리에서** `ProjectCubeLauncher`를 실행합니다. 새 버전이 있으면 자동으로 받은 뒤 게임이 켜집니다.
2. Windows 보호 창이 뜨면 **추가 정보 → 실행**을 누릅니다.

exe를 더블클릭해도 게임은 켜지지만 Steam 오버레이(Shift+Tab)와 초대창이 열리지 않습니다.

## 같이 하기

- 방장: Map에서 `I` 키 → Steam 초대창에서 친구를 골라 초대합니다.
- 친구: 게임을 먼저 켜 둔 상태에서 Steam 채팅으로 온 초대를 수락합니다. 게임이 꺼진 채 수락하면 다른 게임(Spacewar)이 켜집니다.
